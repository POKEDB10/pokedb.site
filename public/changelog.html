v2.0.0 — The Zero-Trust Architecture Overhaul 2026-11-09

Comprehensive system rebuild transitioning from monolith to modular tool registry, Cloudflare R2 direct uploads, SQLite WAL storage, and zero-egress offline utilities.

Added

  • Drop v2 on Cloudflare R2: Direct-to-storage presigned S3 multipart uploads eliminating local disk I/O. Purged Multer completely.
  • Client-Side Cryptography: WebCrypto AES-256-GCM zero-knowledge encryption for Pastebin and File Drop with keys in URL fragment (#k=).
  • Offline Developer Suite: 9 client-side tools running under strict connect-src 'none' CSP (JSON, JWT, Codec, Hash, UUID, Cron, Diff, Minecraft, Sanitizer).
  • Abuse Resistance: Local URLhaus parent-domain walking, Google Safe Browsing Lookup v4 (30m cache), Turnstile bot mitigation, and auto-quarantine upon 3 subnet reports.
  • Cross-Tool Command Palette: Global Ctrl+K palette, keyboard shortcut help, and paste-anywhere clipboard support.
  • Self-Hosted Fonts & WCAG AA: IBM Plex Mono & Sans Latin WOFF2 subsets served locally; 60/60 checks passing across all 12 themes.

Performance

  • 10,000+ req/s Throughput: Decoupled short-link redirects from synchronous persistence via atomic in-memory ClickBufferManager.
  • Zero Leaks Verified: 20-minute soak test stabilized at 0.000 MB/min heap and RSS slopes following initial SQLite WAL buffer warmup.

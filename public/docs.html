Developer API & CLI Reference

All public endpoints support direct CLI usage via curl, wget, or programmatic HTTP clients.

JSON & plain text

1. Shell Functions (Bash / Zsh)

Add these functions to your ~/.bashrc or ~/.zshrc for quick terminal sharing:

# Pipe any text or file into pokedb pastebin
pbpaste() {
  local text="${1:-$(cat)}"
  curl -s -X POST https://paste.pokedb.site/api/paste/create \
    -H "Content-Type: application/json" \
    -d "{\"content\": $(printf '%s' "$text" | jq -sR .)}" | jq -r .url
}

# Shorten any URL from command line
pburl() {
  curl -s -d "url=$1" https://tinyurl.pokedb.site
}

POST /api/shorten

Shorten a destination URL. CLI requests receive a plain-text response with a trailing newline.

# Direct curl usage (returns plain text URL)
curl -d url=https://github.com/POKEDB10 https://tinyurl.pokedb.site

# JSON API usage
curl -X POST https://pokedb.site/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"url":"https://github.com/POKEDB10","customAlias":"my-profile","expiresInDays":30}'
POST /api/paste/create

Create a new code or text paste (max payload 256 KiB).

curl -X POST https://paste.pokedb.site/api/paste/create \
  -H "Content-Type: application/json" \
  -d '{
    "content": "console.log(\"Hello from pokedb!\");",
    "title": "demo.js",
    "language": "javascript",
    "expiresInDays": 7,
    "burnOnRead": false
  }'
GET /raw/:id

Stream raw plain text with strict sandbox; default-src 'none' CSP and nosniff headers.

curl https://paste.pokedb.site/raw/v2PasteCode
GET /healthz

Zero-I/O process liveness probe returning HTTP 200 OK.

curl -i https://pokedb.site/healthz

Last updated: November 2026. Adapted from the Basecamp open-source policies (CC BY 4.0).

1. Privacy Architecture & Information Collected

pokedb.site is built on privacy-by-design principles. We do not require user accounts, email addresses, personal identification, or tracking cookies.

  • Network Telemetry & IP Masking: Client IP addresses are evaluated in volatile memory solely to enforce subnet-level rate limiting (CIDR-based sliding windows) and prevent automated abuse. Client IPs are masked before persisting to any disk or logging system: IPv4 addresses are truncated to their /24 subnet (e.g., 198.51.100.0/24) and IPv6 addresses to their /48 prefix. Raw client IPs are never written to disk.
  • URL Shortener: We record target destination URLs, creation timestamps, expiration rules, and aggregate click counters.
  • Pastebin: We record paste titles, syntax languages, payload text (encrypted client-side when requested), creation timestamps, and view counters. When encrypted client-side, the decryption key resides only in the browser URL fragment (#k=) and is never transmitted to our servers.
  • Drop File Transfers: Drop v2 utilizes direct browser-to-bucket presigned multipart transfers on Cloudflare R2. Zero bytes touch origin server disk. We store the file name, size, expiration date, and sha256 checksum.
  • Offline Developer Tools: All developer utilities (JSON formatter, JWT inspector, UUID generator, Cron parser, Hash studio, Diff tool, Codec, Minecraft MOTD preview, CSS sanitizer) run 100% client-side in the browser. They enforce a Content Security Policy of connect-src 'none', ensuring zero network egress.

2. Retention Periods

Pastes 1 to 365 days (or immediate burn-on-read) Sweeper purge / burn-after-download record deletion
Drop Files 1 to 3 days (or immediate burn-on-download) Cloudflare R2 bucket lifecycle rule & sweeper
Abuse Reports 14 days Automated rolling retention purge
Takedown Audit Logs 90 days Automated rolling audit purge

3. Third-Party Subprocessors & Data Processors

pokedb.site engages the following infrastructure providers and technical data processors to deliver core platform services:

  • Cloudflare, Inc. (Cloudflare Edge, Cloudflare Tunnel & Turnstile): Provides reverse-proxy routing, edge TLS termination, DDoS mitigation, and non-interactive CAPTCHA challenge verification (Turnstile) to protect API endpoints against bot attacks.
  • Cloudflare R2 (Object Storage): Serves as the S3-compatible, geographically distributed object store for presigned multipart file uploads (Drop v2).
  • Google Safe Browsing (Lookup API v4): Scans submitted destination URLs upon short-link creation to protect users against known phishing and malware threats. Advisory provided by Google (https://safebrowsing.google.com/).
  • Sentry (Functional Software, Inc.): Server-side error monitoring and exception tracking (if enabled by operator). All events scrub IP addresses, query tokens, and authorization headers, and 4xx client errors are suppressed.
  • Litestream Replication (Streaming Backups to Cloudflare R2): Continuous WAL snapshot streaming of SQLite state to a private Cloudflare R2 bucket for disaster recovery.

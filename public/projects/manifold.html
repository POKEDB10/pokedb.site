Stack: Java · Netty · ASM Bytecode · Minecraft Protocol Status: Private Repo · Draft Spec

1. Context & Why Private

Manifold attaches via Java Instrumentation API to the game server process, intercepting incoming Netty channel pipelines to route HTTP map renderers (BlueMap, Dynmap), Geyser Bedrock UDP/TCP packets, and Simple Voice Chat streams through a single exposed port.
